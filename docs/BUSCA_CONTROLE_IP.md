# Busca rápida do Controle de IP

O Controle de IP possui uma busca global por IP, nome do equipamento, categoria, unidade, local, andar, setor, patrimônio, patrimônio de CPU ou monitor, usuário responsável, AnyDesk, AETitle, Worklist, modelo, fabricante, MAC, porta, rede Wi-Fi, observações, sistema operacional e status.

Ao começar a digitar, a tela muda automaticamente para **Todos** e pesquisa em todas as categorias, independentemente da aba que estava selecionada. A busca ignora diferenças de maiúsculas, acentos, espaços e pontuação; portanto, termos como `SALA02`, `Sala 02` e `sala-02` podem localizar o mesmo registro. O botão **Limpar busca** retorna à visualização geral.
